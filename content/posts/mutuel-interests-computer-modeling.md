### Computer Modeling

Building machine learning models or using AI to process racing data has become quite popular. These models are typically built on algorithms that take a large number of inputs (past performance data) and create a single output. There could be multiple models for different cases, such as a turf model or maybe a maiden model. Less sophisticated players might only have a single model that attempts to produce a probability of winning.

Access to data is critical when building a model. You need some amount of historical data to train the model on as well as back test it to ensure that it actually has a positive ROI (or close to positive). Horse racing data is really expensive, especially compared to data available for other professional sports. In addition to being expensive, horse racing data is riddled with inaccurate and incorrect data. Ask anyone who's ever created a speed figure how they feel about the timing of races across the United States.

Assuming you have access to the data and can build a model, or have AI build you a model, you can at least get to a point where you are getting probabilities for horses within a race. While building this most of the time spent is on cleaning up the data and figuring out which variables have the most impact on the outcome. This is exactly how one individual can have an edge over another while using the same modeling technology. At this stage though it is very hard to differentiate and finding an edge with models is a constant process. If you find an edge, it doesn't really last for long.
